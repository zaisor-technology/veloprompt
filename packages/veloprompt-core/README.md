# veloprompt-core

Motor de detección y anonimización de datos sensibles de [VeloPrompt](https://zaisor.io/veloprompt).
TypeScript puro, ESM, sin dependencias en runtime y sin llamadas de red.

API: `detect(text, options)`, `redact(text, options)`, `restore(text, map)` y `createSession()`.
Consulta el [README principal](../../README.md) para ver ejemplos, opciones y la lista de reglas.
